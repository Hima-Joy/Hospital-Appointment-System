# Hospital Appointment Booking System

## 📌 Project Description
This is a simple Hospital Appointment Booking System developed using Java (Swing) and MySQL database.

## 💻 Technologies Used
- Java (JDK)
- Java Swing (GUI)
- MySQL
- XAMPP
- MySQL Connector JAR
- VS Code

## ⚙ Features
- Book hospital appointments
- Store patient details
- Connects to MySQL database
- Simple GUI interface

## 🗄 Database
Database Name: hospital  
Table Name: appointments

##  How to Run
1. Install JDK
2. Install XAMPP and start MySQL
3. Add MySQL connector jar file
4. Compile:
   javac -cp ".;lib/mysql-connector-j-9.6.0.jar" HOSPITALAPPOINTMENTSYS.java
5. Run:
   java -cp ".;lib/mysql-connector-j-9.6.0.jar" HOSPITALAPPOINTMENTSYS
